# SpaceStation

A personal start page: clock with live weather (Open-Meteo), saved sites in modules, a Site of Grace fan-art scene that follows day/night and real rain, and a BANG!-style saloon mini-game.

Your modules, sites and layout are saved in your browser only (localStorage), not in this repo.
Right-click the page → **Export backup** / **Import backup…** to move them between devices.

Weather location is set in `PLACE` near the end of `index.html`.
